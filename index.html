About Guitarium

Guitarium is a comprehensive booking and management system specifically designed for music schools offering group lessons. Built with modern web technologies, it provides an intuitive interface for both administrators and students to manage lesson bookings, track attendance, and handle user accounts efficiently.

🗓️ Lesson Management

Easy scheduling and booking system for group music lessons with real-time availability tracking.

👥 User Management

Comprehensive user account system with role-based access for administrators and students.

🔐 Secure Authentication

JWT-based authentication system with secure password handling and session management.

📱 Responsive Design

Mobile-friendly interface that works seamlessly across all devices and screen sizes.

⚡ Real-time Updates

Live booking updates and notifications to keep everyone informed about lesson changes.

📊 Admin Dashboard

Powerful admin interface for managing users, lessons, and system configuration.

Technology Stack

Node.js Express.js MySQL JWT bcrypt HTML5 CSS3 JavaScript Docker CapRover

How It Works

For Students: Log in with your credentials to view available group lessons, book sessions that fit your schedule, and manage your lesson history.

For Administrators: Access the admin dashboard to create user accounts, manage lesson schedules, track attendance, and configure system settings.

For Schools: Deploy the system using Docker and CapRover for easy hosting and management of your music lesson booking platform.
