🎸 Guitarium

Open Source Group Lesson Booking System

About Guitarium

Guitarium is an open source group lesson booking system designed for managing lesson bookings with multiple groups. Perfect for music schools, sports lessons, or any educational institution that offers group-based learning experiences.

Originally developed for guitarium.ee, this system seamlessly integrates with Google Calendar to provide a complete lesson management solution.

Key Features

📅 Google Calendar Integration

Lessons are managed directly in Google Calendar with automatic synchronization and participant tracking.

👥 Unlimited Students & Groups

Support for unlimited number of students and groups, making it scalable for institutions of any size.

🔐 Secure Authentication

JWT-based authentication system with role-based access control for students and administrators.

🎯 Group-Based Learning

Specifically designed for group lessons where multiple students participate in the same session.

📊 Administrative Interface

Comprehensive admin panel for managing users, groups, and lesson schedules.

🌐 Web-Based Platform

Built with Node.js and Express, providing a modern web-based interface accessible from anywhere.

How It Works

The system works by integrating with Google Calendar where lesson titles represent the group name and the description field is used for tracking participants. This approach provides a familiar interface for administrators while maintaining detailed booking records.

Students can log in to view their scheduled lessons, while administrators have full control over creating, modifying, and managing all aspects of the lesson booking system.

Technology Stack

Guitarium is built using modern web technologies including Node.js, Express.js, MySQL, and integrates with Google APIs for calendar functionality. The system uses JWT for secure authentication and bcrypt for password hashing.
